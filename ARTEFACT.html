4. Cross-Cutting Observations

Data Quality Issues Identified

  1. Date format inconsistencies: Multiple formats in the same column
  2. Column name inconsistencies: Same product identifier named differently across tables
  3. Sentinel values: #N/A, -1, 9999 used as sentinels
  4. Currency formatting: Plain numbers, comma-separated, Rs-prefixed, quoted variants
  5. Territory aliases: Bombay/BLR used interchangeably
  6. Duplicate SKU entries: Lowercase/uppercase duplicates in dim_sku

Methodology

Data loaded from 8 CSV files, cleaned through a pipeline normalizing column names, dates, sentinel values, and geographical aliases. Intent-specific agents (WHAT, WHY, WHAT_TO_DO) query the cleaned data and return evidence-grounded answers. Confidence thresholds determine status: OK (≥0.7), PENDING_APPROVAL (0.3–0.7), ABSTAINED (<0.3).
